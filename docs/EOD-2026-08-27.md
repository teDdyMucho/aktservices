## 2. NEW FEATURE — MARKETING ADS MODULE

### Public
| Route | What it shows |
|-------|---------------|
| `/marketing` | One **collection card** per published folder — cover media, "Collection" tag, image/video counts, hover "Open" pill. Whole card is the link. Unsorted ads grouped as one "All ads / More ads" card (reserved slug `other`) |
| `/marketing/[slug]` | Every ad inside the folder as a **uniform 16:9 tile** with tabs **All · Videos · Images** (All = default, videos listed first). Hash-synced (`#all/#videos/#images`) |
| `/api/marketing` | Public JSON of published ads (`?limit`, `?folder=<slug>`) — feeds the homepage panel |

- "Marketing" tab added to the site Nav (desktop + mobile) and to `sitemap.ts`
- Admins see a "Manage ads" shortcut on the public page
- **Ad cards have no titles** — titles belong to the collection only (a per-ad description still shows if one was written)
- **Revolving neon-green border** (`.neon-ring` in `globals.css`) on collection cards and ad cards — conic-gradient sweep, 3.2s loop, glow brightens on hover, disabled under `prefers-reduced-motion`

### Media tile behavior (`components/AdMediaTile.tsx`, shared by public + admin grids)
- Fixed 16:9 frame with media absolutely positioned — a portrait file can no longer stretch the card (this was why cards were uneven)
- Cards never play inline; play button only:
  - **Landscape video** → big **full-view overlay** sized to the video's own aspect ratio (up to 94vw/86vh), native controls, autoplay; ✕ / Esc / backdrop closes
  - **Portrait video** → native **fullscreen**, letterboxed so it stays portrait; exiting fullscreen resets the tile
- Images → lightbox on the public page
- Global CSS fix: `video:fullscreen { object-fit: contain }` — fullscreen previously inherited `object-cover` and cropped portrait videos into fake landscape

### Admin (`/admin/content/marketing` → `components/admin/MarketingManager.tsx`)
- Linked from the Content hub as a live (not code-managed) module
- **Folders:** create (name + description, slug auto-generated with collision handling), rename, hide/show, delete (cascades ads + Storage files with explicit warning). Chips: All · Unsorted · each folder with live counts
- **Multi-file upload:** drop or pick many images/videos at once into a chosen folder; per-file preview, editable title (defaults to filename), shared description; 3 concurrent uploads; per-file status with individual retry
- Per ad: hide/show, edit (title/description/**move between folders**), delete
- Upload path: browser → `POST /api/admin/marketing/upload-url` (signed URL) → **direct upload to Supabase Storage** → `POST /api/admin/marketing` records the row. Keeps large videos out of the serverless body limit; server verifies the object exists before recording it
- Limits: images 10 MB (JPG/PNG/WebP/GIF/AVIF), videos 100 MB (MP4/WebM/MOV)
